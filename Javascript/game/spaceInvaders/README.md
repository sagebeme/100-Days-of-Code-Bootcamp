# Space Invaders - Word Shooter

Welcome to the Space Invaders game where you shoot words instead of aliens! This project is built using HTML, CSS, and JavaScript.

## Getting Started

### How to Play
- Move the player ship using the left and right arrow keys.
- Shoot projectiles (letters) by pressing the spacebar.
- Destroy the invaders by hitting them with the correct letters.


### Project Structure
- index.html: HTML file containing the game canvas.
- style.css: CSS file for styling the game.
- script.js: JavaScript file containing the game logic.


### Features
- Player ship movement and shooting.
- Word generation for invaders.
- Collision detection between projectiles and invaders.
- Scoring system.

### Contributing
Feel free to contribute to the project by opening issues or submitting pull requests. Your feedback and enhancements are welcome!
