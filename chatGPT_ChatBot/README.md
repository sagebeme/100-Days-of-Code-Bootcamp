# Chat Application

This is a simple chat application built with HTML, Bootstrap, JavaScript, and FastAPI. The application allows users to send messages, which are then processed by the OpenAI API to generate responses.

## Features

- User-friendly chat interface
- Different background colors for user messages and AI responses
- Backend integration with OpenAI API

## Prerequisites

Before you begin, ensure you have met the following requirements:

- Python 3.7 or higher
- `pip` package manager
- OpenAI API key
